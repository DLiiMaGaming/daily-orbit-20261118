# The Daily Orbit — 18 November 2026

This program draws a complete newspaper front page summing up the world's news of Wednesday 18 November 2026 — masthead, lead story, secondary stories, briefs and a day-in-numbers box — entirely in Python standard library, and writes it as a deterministic 1024x1024 PNG. Run it with `MAKEFUN_OUTPUT_DIR=out python3 main.py` and the front page appears at `out/entry.png`.
